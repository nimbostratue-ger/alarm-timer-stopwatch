# Timer App (Alarm • Timer • Stopwatch • HIIT / Repeated Timer)

A modern, lightweight, and user-friendly timer application that includes multiple time-tracking tools in one place.  
Perfect for productivity, workouts, studying, and daily routines.  
**Clean interface and accurate countdown.**  
The app allows managing all timers in a single GUI interface and stores timers in **localStorage**, so it remembers the timers you have already set.

## Try the App
You can try the app directly using the website:  
[http://localhost:5173/alarm-timer-stopwatch/](http://localhost:5173/alarm-timer-stopwatch/)

## Features

### 1. Alarm
- Set an alarm for a specific time.
- Choose the exact **days of the week** the alarm should repeat on.
- After creating an alarm, you can **edit and change the assigned days** at any time.
- Plays an audio alert when the alarm time is reached.

### 2. Countdown Timer
- Set any duration (hours, minutes, seconds).
- Audio alert when the timer finishes.

### 3. Stopwatch
- Start, pause, resume, and reset.
- High-precision timing.

### 4. HIIT / Repeated Timer
A high-intensity interval training mode that includes:

- **Work Time** (active interval)  
- **Pause Time** (rest interval)  
- **Repeat Count** (number of cycles)  
- Automatically cycles through work → pause → work → pause  
- **Only HIIT mode supports repeating**  
- Ideal for workouts, Pomodoro cycles, or habit routines.
